# GTA Six, Everything We Know: 2x2 Grid Prompts (Part 2 of 2) (4 shots per image)

Each prompt makes **one 16:9 image containing a 2x2 grid of four 16:9 frames**: four consecutive shots of the voiceover, read top-left → top-right → bottom-left → bottom-right. Crop each image into quarters to get four frames for your timeline.

**Style target:** the reference video, i.e. a polished 2D vector tech explainer with solid-white round-headed stick figures in clothes, clean black outlines, detailed cluttered backgrounds, soft gradients, dramatic neon glows (Miami-style pink and teal here) and bold sans-serif captions.

**Cropping:** each 3840x2160 image splits into four 1920x1080 frames (cut at x=1920 and y=1080; trim the thin white gutter). If your tool outputs a smaller size, cut it into equal quarters the same way.
